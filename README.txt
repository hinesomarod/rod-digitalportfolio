ROD CHRISTIAN ARVIN O. HINES — DIGITAL PORTFOLIO
================================================

Files:
- index.html: portfolio content
- style.css: pink visual design and responsive layout
- script.js: mobile navigation
- assets/rod-christian-arvin.png: profile portrait
- Rod-Christian-Arvin-Hines-Resume.pdf: downloadable resume

LOCAL PREVIEW:
Open index.html in a browser, or open the folder in Visual Studio Code and use Live Server.

PUBLISH WITH GITHUB PAGES:
1. Create a PUBLIC GitHub repository named rod-christian-arvin-portfolio.
2. Upload all files and folders in this package to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish. The URL will be:
   https://YOUR-GITHUB-USERNAME.github.io/rod-christian-arvin-portfolio/

Keep the assets folder and resume PDF in the repository so the portrait and download button work.
